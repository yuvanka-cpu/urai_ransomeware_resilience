## Reviewer checklist

For each use case, confirm that the objective is distinct, the scenario family is sector-appropriate, the listed evidence is observable, the dashboard output is explanatory, the recommendation is review-only, the safety statement blocks real or operational action, and every acceptance metric is measurable. Record uncertainty instead of adding unverified physical-state assumptions.
